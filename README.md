### ** Image Categorization Using ResNet50**  

This project focuses on developing an image classification model using the ResNet50 architecture to accurately categorize images into predefined classes.
By utilizing transfer learning, the model is fine-tuned to identify distinctive visual features such as shapes, textures, and color patterns that differentiate each category.

By the end of this project, the trained model will be optimized for general-purpose image classification tasks, enabling efficient and accurate categorization for applications such as content organization, visual search, and automated tagging.
